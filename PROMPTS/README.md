# Variant prompts

Shorter prompts, one topic each, for an AI coding agent. Each one works on its own; together they
cover what PROMPT.md covers. Give the agent this repository as well: every prompt points at the
real code that implements its topic, so the agent can read the source instead of guessing.

| File | Use it to |
|---|---|
| 01-layout.md | rebuild or adapt the street plan, river, squares, lanes and lots |
| 02-buildings.md | generate the townhouses |
| 03-landmarks.md | build the cathedral, market hall, town hall and towers |
| 04-streets-and-furniture.md | lay the ground surfaces and street furniture |
| 05-lighting-and-atmosphere.md | reproduce the dusk look |
| 06-integrate-into-existing-game.md | drop the generator into another game |
